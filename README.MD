# marcelloreis-bot
O programa de Olho na Energia foi criado para auxiliar os consumidores a ter um consumo mais consciente de energia, melhorar o controle de gastos e melhorar o planeta.
Foi utilizada a linguagem Python na sua estruturação. As fórmulas aplicadas foram:
•    consumo_mensal = (potencia * horas_dia * 30) / 1000
•    custo_estimado = (consumo_mensal * 0.75)

Para fazer uso do Programa basta informar: o aparelho, a potência, o tempo de uso diário.
